## Project Overview

This project implements and evaluates a 4×4×4 matrix multiplication unit using Verilog RTL and follows an RTL-to-GDSII ASIC design flow using the SKY130 PDK.

The project covers:

1. RTL design and functional verification
2. Logic synthesis
3. Static timing analysis
4. Physical design
5. Final layout and design-rule verification
